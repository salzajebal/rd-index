---
name: VORA modal design language
description: Visual rule for all modal, alert, and sheet surfaces.
---

VORA Markets uses a sharp-edged interface: every modal surface and its nested controls must use square corners, not rounded cards or pills.

**Why:** The landing and trading interface are built around straight grid lines and rectangular panels; rounded modal controls break that visual language.

**How to apply:** Preserve zero-radius styling for new dialogs, alerts, sheets, inputs, buttons, badges, and icon containers placed inside modal content.
